PELIC practical help: a large CSV without a complicated setup

Download the official compiled CSV before class. Excel can filter anon_id and class_id. If importing the complete file is slow, use this optional Python 3 helper to make a small personal analysis copy; no extra package is needed.

Download extract_pelic.py · Official CSV

python3 extract_pelic.py PELIC_compiled.csv --list
python3 extract_pelic.py PELIC_compiled.csv --learner YOUR_ID --output learner.csv

Replace YOUR_ID with an ID from the list. The helper defaults to writing classes, preserves the text and retains task/version metadata. It does not select the “best” learner or analyze their ability. Open learner.csv in a spreadsheet and choose two comparable samples. Look up prompts in question.csv. If Python is unfamiliar, use NICT JLE’s plain-text route.

Worked example · from an observation to a design choice

Synthetic teaching example, not a real corpus record. Use a real accessible corpus learner for the assignment.

Sample A · an invented past narrative
Yesterday I go to the market. I bought apples. Then I meet my friend. We talked for an hour.

Sample B · a second invented narrative
Last Saturday I visited my aunt. I buy a cake. Later I walked home. I watch a film.
A narrow claim, with an explicit denominator
EvidenceInterpretationDesign and check
Eight finite verbs in explicitly past-time clauses. Four successful past forms: bought, talked, visited, walked. Four mismatches: go, meet, buy, watch.Past marking is inconsistent in these samples (4/8 mismatches). The learner already sequences events and uses some past forms. Cause and spoken ability remain unknown.Model a short past narrative → notice time cues → reconstruct events with a verb bank → retell a new event without the bank. Check past forms in required contexts and whether the listener understands the sequence.

This count is a classroom coding decision, not a standardized proficiency score. A new narrative with different content checks transfer more usefully than copying corrected sentences.
