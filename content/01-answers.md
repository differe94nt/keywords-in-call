# Step 1 · What the class submitted

Answers load straight from the response sheet. Names are hidden by default, so anyone can be asked to talk about any entry.

Read across the two columns: **what the AI wrote** next to **what the student wrote**. The gap between them is the lesson.

## How we read these

- Pick an entry. Read the AI summary, then the student summary.
- Name one sentence in the AI summary you could trace to a page in a real paper.
- Name one sentence you could not.
- Decide which it is: false, unsupported, or too general to be wrong.

## Discussion prompts

- Which sentence in this AI summary is hardest to trace to a specific study?
- Does this summary report findings, or only topics? Count the verbs "explores" and "investigates".
- Five studies must disagree somewhere. Does this summary let you see where?
- Are the numbers in this summary the studies' own numbers?
- Whose conditions got dropped — which learners, how long, measured how?
- This student disagreed with the AI. What did they see that the AI missed?
- Would this summary read the same if the five papers were swapped for five others?
- The student summary is shorter. Is anything important in it that the AI left out?
